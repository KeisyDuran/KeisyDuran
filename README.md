Hola, soy **Keisy** 👋, desarrolladora de software en Santo Domingo. Diseño la base de datos, escribo la API, construyo la interfaz, la pruebo y la pongo en producción. Tengo **dos sistemas míos funcionando a diario**: [Tour Manager](https://www.tourmanager.com.do), un SaaS para agencias de turismo, y el Sistema de Inventario de Servidores del Registro Inmobiliario.

> 🟢 **Abierta a nuevas oportunidades** en backend .NET, sin dejar de tocar el resto del sistema.

<br>

## 🎩 Cuatro sombreros, un mismo sistema

| | Rol | Lo que he hecho |
|:-:|---|---|
| 🟣 | **Backend** | APIs REST con ASP.NET Core y Next.js · 120 endpoints en Tour Manager · SQL Server, PostgreSQL, EF Core y Prisma · JWT, LDAP, roles y auditoría |
| 🟠 | **Frontend** | Catálogo público y panel de 21 pantallas en 5 idiomas · React, Next.js, Razor y .NET MAUI · Diseño adaptable al celular |
| 🟢 | **QA** | Más de 600 pruebas automatizadas con Vitest · Casos de prueba y defectos en Azure DevOps (SAVA, SGA, ARI) · Ningún despliegue sin verificar |
| 🟡 | **Infraestructura** | IIS y Windows Server · Vercel con dominio propio · Docker · VMware y Hyper-V · PowerShell sobre Active Directory |
