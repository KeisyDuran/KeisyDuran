### 🎯 Sobre mí

- 💻 **Desarrolladora de software backend** con más de tres años creando aplicaciones del lado del servidor sobre tecnologías Microsoft.
- 🚀 Autora de **dos sistemas en producción**: el Sistema de Inventario de Servidores del Registro Inmobiliario y **Tour Manager Pro**, un SaaS multiempresa con 120 endpoints REST.
- 🔐 Seguridad a nivel de código: Active Directory (LDAP), JWT, control de acceso por roles, auditoría y limitación de peticiones.
- 🖧 Vengo de infraestructura (Windows Server, IIS, VMware), así que desarrollo pensando también en dónde corre el software.
- 🎓 Estudiante de **Ingeniería de Software** en UNICARIBE · Tecnóloga en Redes de la Información (ITLA).
- 📍 Santo Domingo, República Dominicana.
